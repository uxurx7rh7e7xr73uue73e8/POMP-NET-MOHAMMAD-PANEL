## 🚀 استقرار در Railway

1. مخزن را به Railway متصل کنید.
2. مطمئن شوید که Build از `Dockerfile` استفاده می‌کند.
3. گزارش ساخت را بررسی کنید.
4. پس از موفقیت Build، دامنه عمومی را تنظیم کنید.
5. ورود مدیر، مدیریت کاربران، اشتراک‌ها و ذخیره‌سازی را آزمایش کنید.

برنامه از متغیر محیطی `PORT` استفاده می‌کند و در صورت نبود آن، پورت `8080` را به کار می‌گیرد.
