# ✦ POMP NET MOHAMMAD 👑

پنل مدیریتی اختصاصی POMP NET، مبتنی بر هسته واقعی SpiderPanel.

## قابلیت‌های هسته اصلی

- مدیریت کاربران و اشتراک‌ها
- مدیریت لینک‌ها و QR Code
- مدیریت نودها و Workerها
- ابزارهای Scanner
- قابلیت‌های اتوماسیون تلگرام
- صفحات ورود و اشتراک
- رابط کاربری واکنش‌گرا

## اجرای Railway

1. مخزن را به Railway متصل کنید.
2. اجازه دهید پروژه از Dockerfile ساخته شود.
3. پس از ساخت موفق، دامنه عمومی را از Railway ایجاد کنید.
4. مسیر پنل را با `/spider` بررسی کنید.

پورت برنامه: `8080`
