## 🚀 استقرار روی Railway

1. مخزن را به Railway متصل کنید.
2. اجازه دهید Dockerfile اجرا شود.
3. گزارش Build را بررسی کنید.
4. پس از موفقیت Build، دامنه عمومی را ایجاد کنید.
5. ورود، اشتراک‌ها، ذخیره‌سازی و قابلیت‌های موردنیاز را آزمایش کنید.

پورت پیش‌فرض برنامه: `8080`
